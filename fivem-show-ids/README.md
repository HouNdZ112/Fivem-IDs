# FiveM Show Player IDs

## Overview
This script allows players to display the IDs of all other players above their heads in a 3D text format when the "U" key is pressed.

## Installation
1. Download the `show-ids` folder.
2. Place the folder in your FiveM resources directory.
3. Add `ensure show-ids` to your server cfg file.

## Config
1. In the config you are able to change the size and colour of the text when a player uses the id script. 
2. You can also change the distance that players can see the IDs from. 
3. You are also able to change the keybind that players press to be able to show ids.
